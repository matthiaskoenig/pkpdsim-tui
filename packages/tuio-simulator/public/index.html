Objects

  • Double click empty space places the next object
  • Right double click picks which object to place
  • Drag an object moves it
  • Scroll over an object turns it, with shift for finer steps
  • Middle click an object removes it

Touches

  • Click empty space is a tap: the finger stays down long enough for the table to take it as a choice
  • Hold the button on one spot is a finger resting there
  • Drag empty space is a finger moving across the glass

Choosing and going back

A table opens when a finger rests on something for a moment. On the body, tap a card or the organ it points at. In a table, a finger held on a number, an object or an organ opens the note which says what it is.

Back in the panel of a table returns to the body, and so does the table switch beside it.
