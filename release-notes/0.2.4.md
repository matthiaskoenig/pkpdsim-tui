# Release notes for pkpdsim-tui 0.2.4

The drug table runs while a hand is on it, and reads the course of ten tablets at the resolution it reads one. The documentation is in the order somebody meets it, and no command of this repository is typed with a `--` in it any more.

## The course no longer starts over under the hand

The table of the drug runs its course by itself: the tablet dissolves, the plasma rises, the body fills and empties, over eighteen seconds, and then it begins again. It also started again from the first minute every time the individual changed, and a hand on a dial changes the individual many times a second. A visitor who turned the dose, the dissolution or the genotype therefore watched the first minutes of the first hour over and over, and the drug never reached the blood while they were touching the table. The one thing the table is about was the one thing a hand prevented.

The course now keeps running while the objects are moved, and the new answer is drawn under the cursor where it stands. It starts over only when the window itself changes, which is the number of tablets: a course of one day and a course of ten are two different pictures. The liver table had the same clock and the same fault, where the dial of the regeneration rate held the days at the operation, and it keeps running too; a different operation is still a new course.

## The course of ten tablets is read as finely as the course of one

The output grid was a fixed number of points spread over whatever window was asked for: 241 points of a day, which is one every six minutes, but the same 721 points of ten days, which is one every twenty. The peak of each morning was then sampled at a different place on each of the ten days, so ten peaks which are the same height were drawn as ten peaks of different heights, and the numbers of the band were read off that same coarse grid.

The grid is now five minutes of the course per point, whatever is asked for: 289 points of one day, 2881 of ten. The solver answers a day of it in about 2 ms and ten days in about 15 ms, and the surface draws the longer path at the rate it drew the short one, so nothing of the table is slower for it.

## The half life of ten tablets is the half life of the drug

Found while reading the band of a course of ten tablets: the half life said 173 hours, which is a week. It is read as the slope of the last third of the course, where a course of one tablet is a clean fall; the last third of a course of ten tablets holds three more mornings, and a line through those three peaks is almost flat. The fit now starts at the last peak of the course, whatever its length, which is where the drug is only leaving the body. A course of ten tablets says 4.2 hours.

## The documentation reads in the order somebody meets it

The landing page carried the whole quick start, the simulator came before the table, and what a visitor chooses was in with the recorded clips. The pages now go from what a visitor sees to how it is made: the overview, [the applications](https://matthiaskoenig.github.io/pkpdsim-tui/apps/), [a real table](https://matthiaskoenig.github.io/pkpdsim-tui/table/), [the simulator](https://matthiaskoenig.github.io/pkpdsim-tui/simulator/), development, and the voice.

The settings and the levels are explained where a visitor meets them, with the four tables, as one table of what an address carries. What a booth needs is on one page, from `git clone` to what to check before an audience arrives. The simulator page is half of what it was: run the table against it, drive it, and what to do when nothing arrives. The README is an overview and a list of the pages rather than a second copy of the commands.

## Nobody types a double dash

`npm run table -- --tuio 10.0.0.20:3343` carried a separator nothing of this repository asked for. It is npm's: npm reads the flags of a command as its own, and `--` is what hands the rest to the script. A booth typing a line it has to get right should not have to know that.

```bash
npm run table                 # the table of this exhibition
npm run table:preview         # the same, serving the build
node scripts/table.mjs --tuio 10.0.0.21:3343 --ids 2,4,8,9,14,15,22
node packages/tuio-simulator/src/server.mjs --host 0.0.0.0 --rate 30
```

A command of `package.json` is a line with its options already written down, and a line with options of its own is said to the script, where no npm stands in between. `npm run table:preview` is the one case a booth needs which had no command of its own: it is `npm run table` with `--preview`, so the tracker and the pucks of the exhibition are still written down once.

## How this was checked

The table was driven by the tracker, in a browser which was given no touch of its own, with a hand which keeps turning an object: the course walks straight through the turn where it had been pinned at the first minutes of the first tablet. The grid and the half life were measured on the worker the table itself runs, and every element of the drug table and of the liver table was pressed by a finger of the tracker at 1920 by 1080 and at 3840 by 2160.
