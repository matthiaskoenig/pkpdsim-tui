# Release notes for pkpdsim-tui 0.2.1

The pucks of the exhibition table: `npm run table` carries the ids printed on the markers of this table, which are 5, 6, 11, 12, 21 and 22.

## The markers of this table

```bash
npm run table
# which is: node scripts/dev.mjs --no-simulator --tuio 10.0.0.20:3343 --ids 5,6,11,12,21,22
```

The objects of a table are numbered from 1 in the application, and a real table brings whatever was printed on its pucks. The `--ids` of that one command says them, in the order the objects of a table are picked up, and every page the server serves is given them: the page a visitor is handed, the page a table opens again after a visit, and a page somebody typed.

Six pucks, because the table with the most objects reads six: the drug through the body, whose objects are the dose, how fast the tablet dissolves, the CYP2C9 genotype, the liver, the kidneys and the tablets a day. The circulation reads 5, 6 and 11, liver surgery reads 5 and 6, the liver on the machine reads 5, 6, 11 and 12, and all four were opened on this list to see that each reads its own.

Another table is the same command with its own two, either in `package.json` or after `--`:

```bash
npm run table -- --tuio 10.0.0.21:3343 --ids 2,4,8,9,14,15,22
```

See [Run on a table](https://matthiaskoenig.github.io/pkpdsim-tui/table/) for the whole of it, and 0.2.0 for the release this is a patch of: the resources of a table travel with a release, so a clone of this one is a table.
